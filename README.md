# Responsive Personal Portfolio Website

A professional, accessible and fully responsive personal portfolio built with semantic HTML5, modular CSS and vanilla JavaScript.

## Features

- Semantic HTML5 structure: `header`, `nav`, `main`, `section`, `footer`
- Responsive mobile-first layout
- Mobile hamburger navigation
- CSS Grid and Flexbox layouts
- Accessible navigation, labels, focus states and ARIA attributes
- Contact form with client-side validation
- Smooth scrolling and active navigation highlighting
- Reduced-motion support
- Cross-browser friendly vanilla HTML/CSS/JS
- No framework or build step required

## How to Run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click it in a browser.
4. Edit your personal information, projects, links and images.

## Customization

- Change colors and design tokens in `css/variables.css`.
- Change general component styling in `css/style.css`.
- Change breakpoints in `css/responsive.css`.
- Update navigation and form behavior in `js/navigation.js`.
- Replace the profile/project placeholders with your own optimized images in `images/`.

## Contact Form

The form currently performs browser-side validation only. To receive real submissions, connect it to a backend or a form service and keep server-side validation enabled.

## Accessibility

The project includes:

- Skip-to-content link
- Semantic landmarks
- Descriptive labels
- Keyboard-accessible navigation
- ARIA-expanded navigation state
- Live form status
- Visible focus states
- Reduced-motion preference support
- Accessible image/visual descriptions

## Browser Testing

Test the site in current versions of Chrome, Edge, Firefox and Safari. Also test at mobile, tablet and desktop widths.

## Deployment

This static site can be deployed on GitHub Pages, Netlify, Vercel or another static hosting provider.
